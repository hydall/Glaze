## plugins

- **plugins moved from Nightly to the stable build**
- plugin pages from **Tavo Hub** open right in Glaze, and `.tpg` files import directly. plugins installed from the hub check for updates on their own
- **a permission matrix**: you decide what a plugin can reach, down to individual websites. permissions are grouped, each group has a switch for all of it, and internet access is its own group with a list of sites
- **a request history**: what a plugin asked for, what it was allowed and what it wasn't. every plugin request (text and image generation, network calls) shows in the inspector's requests tab
- plugin panels draw **over the chat interface** without getting access to the chat itself, and no longer hide under the keyboard
- a plugin can get **its own API preset per feature**: say, chat replies on a strong model and background work on a cheap one. for images you pick the generation service and the style
- the plugin page got tabs, and each plugin's data can be **exported and imported** as JSON
- the chat tools have a new **Plugins** card
- and the other perks of having our own framework, which you can look up in the docs

## ExtBlocks

still polishing extBlocks, with mixed success

- **the original's triggers**: on the user's message, on the reply or on both, with keyword and period conditions
- blocks can **inject into the prompt**, hide and run in the background
- **rewrite blocks** rewrite the message itself (whole or in pieces), and the message menu has a new Rewrite… entry
- **accumulation blocks**: a YAML state updated with MongoDB-style operators (`$set`, `$inc`, `$push` and the rest)
- a new **In the message text** display mode: the block is appended to the reply, so regexes that styled it in SillyTavern style it here too
- **generation profiles** (big / medium / small) and grouped requests
- the original's macros: `{{ExtBlocks::name}}`, `{{mainPrompt}}`, `{{wiBefore}}` / `{{wiAfter}}` / `{{wiAll}}`
- **a context list editor**, the counterpart of the Context Builder
- blocks **embedded in the character card** are picked up automatically
- **scripts** written for the original run in Glaze's sandbox
- the card and persona in the blocks' context are always built correctly, even when the preset switches the standard blocks off

## presets and API

- **NoAssistant is back on the preset**, as in the Vue version, and its stop string now expands macros: `{{user}}:` finally stops on your persona's name. **heads up**: if you turned NoAssistant on in the connection settings on 0.8.x, turn it on again in the preset
- the NoAssistant stop string now goes out to Anthropic and Gemini as well
- the preset's advanced settings are split into separate groups: reasoning, prompt postprocessing, impersonation
- **Renri is updated** (Dream Engine GODDESS LITE 5.51). if you edited the old one, your copy is kept as "Old Renri"
- the tokenizer switches as soon as the model is picked, not a second later
- with "use LLM API" on for embeddings and no model set, the chat model no longer goes to `/embeddings`. embedding errors are readable now

## backups

- backup export has an **Include API keys** switch, off by default. without it the archive leaves out provider keys, catalog logins and the Dropbox/Google Drive tokens

## inspector

- requests can be filtered by type, and long titles are no longer cut off
- old requests no longer vanish from the history once a chat passes 50 of them, and embedding indexing no longer pushes generation requests out

## fixes

- **the chat no longer freezes solid** on a display regex stuck on some message: such a script is stopped after 3 seconds and switched off until the app restarts
- personas: the list opened from a chat marks the persona the chat actually uses (chat and character bindings included), and a tap rebinds that chat
- when Continue fails, the notice now says why, and the reason can be copied
- the token count no longer disappears after a regenerated reply
- asterisk text no longer vanishes from notifications, and italics inside quotes keep the quote colour
- on iOS, chat images save to Photos
- new Actions entries save even when the keyboard closed the drawer
- the Material You theme preview uses the system colours
- lorebooks extracted from JanitorAI are no longer saved globally enabled, and the opening line no longer repeats among the alternate greetings

and, as usual, a pile of small interface fixes on phone and desktop
