## summary

- **history compaction into summary blocks** reaches the stable build: once the prompt fills a set share of the context, old messages are retold as a block and sent in their place. blocks of one level merge a level up, and the merged ones go to an archive
- manual **Compact history** works through the whole backlog in the background and keeps going with the Memory sheet closed. the action bar shows which block is being written, how many are left and the time elapsed
- the automatic run compacts down to a set line instead of stopping after the first block. the compaction settings show the chat's own numbers: fixed part, summary, history and what a run would leave
- blocks are inserted **in place of their messages** (`in_place` mode, the default for new presets)
- a block can be **regenerated** into a draft
- retell and merge prompts are picked from a preset library, as in Memory Books
- the summary carries over when a chat is branched and works on regenerations

## chat

- **the chat header, composer and drawer** are now drawn inside the chat WebView
- **phone landscape layout**: a side tab rail (can be moved to the left), the composer and tools drawer in their own strip. the portrait lock is removed
- the chat model can **create and edit characters** through tool calls, including their picture
- a copy button in code block headers
- "Pin cache anchor" in the message menu: the history starts at that message while it still fits
- the inspector's context bar marks the stepped trim's lines
- the inspector shows saved requests as a flat list, with responses matched to them

## themes

- a theme can carry **its own chat layout**: templates and CSS for messages, header, composer, drawer and tabs
- **Tavo theme import**
- the theme editor preview is the real chat page and updates live
- corner rounding settings; rounding is now part of the theme
- safe-area insets are available to theme CSS (`--sat`, `--sab`)

## regex

- folders, multi-select and sorting in the regex list, as in the presets list. manual order is the run order
- SillyTavern tracker presets work end to end
- one set of rules for where a script runs, however the file states it

## catalog and lorebooks

- long closed lorebooks are built **in several requests**. the request size is set in the build settings (24k tokens by default)
- JanitorAI's queue (Cloudflare Waiting Room) is waited out instead of failing, with a time estimate
- on a Character + lorebooks import the lorebook sheet opens right away. a separate LLM slot for lorebook builds
- first messages also trigger a closed lorebook capture

## image generation

- new **TensorArt** provider
- redraw a picture inside an in-message ExtBlock
- a generated picture keeps the layout the card gives it

## plugins and ExtBlocks

- original ExtBlocks scripts with a UI (buttons, windows, timers, localStorage) run on a persistent page over the chat. enabled by the `chat_page` preset permission, off by default
- plugin packages are served to their frames over loopback; loopback access no longer needs the local network switch
- plugin floating windows can cover the header and composer and stay inside the safe area
- Tavo regex display/prompt scope is kept

## Windows

- **a setup of our own**, styled like the app: per-user install without admin rights, shortcuts, one install per channel. user data is never touched
- stable updates install from inside the app through the setup
- the setup leaves an older version's shortcuts alone and brings its logins over

## presets

- **NoriMyn updated** (4Argon 3.8 Flash). an edited copy is kept as Old NoriMyn
- preset export is readable by SillyTavern
