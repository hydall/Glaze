by the number it's another small patch, but in practice enough piled up for a proper update: message translation, in-app guides, Tavo import, crash logs and a great many small fixes

## translation

- the API settings' Agents tab got a **Translation** slot. translate with the chat model or a dedicated service: **DeepL, Google, Yandex or LibreTranslate**
- every message now has a **translate button** next to its menu. the translation is display-only: the prompt, the editor and copy still get the original
- the composer's **Translate** action translates your draft into the roleplay language (and can undo it). it can be pinned to the composer row
- **auto-translation**: of your own messages when sending (the model then gets the translation) and of character messages when receiving (on screen only, the model keeps the original)
- the model's translation prompt is editable and can be saved as presets

## guides and onboarding

- **screen guides**: the first time you open them, the tabs, chat, characters, tools, API, presets and personas spotlight what's where and how to set it up. on desktop the tabs, characters and tools are one shared tour
- onboarding was reworked: a greeting slide, a features grid, **a slide of its own for the glossary** and **a preset pick** — a built-in one or your own .json. API and persona setup moved into the guides
- More has a new **Help** group: replay onboarding and the guides, the glossary and the logs
- JanitorAI's closed-lorebook extractor walks you through its steps on first open, right over the real sheet
- notifications are asked for even if you skip onboarding before reaching their slide

## chat

- when a reply was cut off because it **hit the output token cap** (Max Tokens) rather than because the model finished it, you now get told so
- Max Tokens can no longer exceed the context size, and if the preset doesn't fit into the context minus Max Tokens, the app says so instead of letting you send blind
- while a generation is stopping, the typing bubble says "Aborting…" instead of "Generating…"
- editing a message **no longer gets stuck**: the composer and regenerate aren't locked until a restart
- image attachments survive a message edit
- a quick swipe counts even when the finger stops short of the threshold
- **Enter to send** only fires from a physical keyboard and is off by default: the Samsung Keyboard no longer sends the message instead of a line break
- generated images are saved to the Glaze folder instead of going through Share

## characters and catalog

- characters have a new **Appearance** field. image generation sends it to models that can't take references (or when you pick it)
- **creator pages** for JanitorAI and Chub: tap the author to open their cards
- a redesigned **filter sheet**; Chub tags come from its full tag index and can be searched
- the JanitorAI lorebook extractor marks public lorebooks you've already downloaded, closes itself once everything is out, and asks before closing when nothing has been saved yet
- when a triggered lorebook hits JanitorAI's 120k-token cap, the trigger is split and re-run piece by piece in fresh chats, so entries no longer get lost
- the "created by … on janitorai.com" credit is stripped from JanitorAI cards
- when JanitorAI keeps answering 401 (mostly behind a VPN), the catalog offers to **log in again** instead of just showing an error
- empty chat and character lists got illustrations

## lorebooks

- lorebook settings now sit **right above the entries** instead of on a separate page
- **vector auto-indexing**: saved lorebooks are embedded in the background
- vector settings are always visible, and when embeddings aren't set up, the app explains why and opens the right tab

## backups and sync

- **Tavo backup import (.tbk)**: characters, personas, lorebooks, presets, chats with swipes and memory, API and regex
- cloud sync now actually syncs **API keys** (when that's on) and carries the chat layout

## presets and API

- new connections have **streaming off** by default, and every generation timeout is raised to 120 seconds
- the model list is dropped when the endpoint or key changes
- switching protocols rebuilds the URL properly: Gemini's `v1beta` no longer sticks to other endpoints
- **Shino**: the reply plan in `<rp_plan>` no longer leaks into the reply, and the language block is off by default
- built-in presets show up in the list on the very first launch, not after a restart
- preset blocks that use variables have their SET/GET badges back
- **extBlocks** honour the block's context list and `apply_regex`, keep images out of the context and expand `{{persona}}`

## look

- **device theme**: a theme now has a type (dark, light or same as device), and settings have "Follow device theme" with separate themes for the light and dark modes
- the theme list shows the real Material You colour
- the big floating action button is back
- bottom sheets moved onto the Glaze kit and got a top-edge outline

## desktop

- chat search in the header, next to the session name
- right sidebar panels animate open and closed and lay out flat, and the tools hub got a header
- a hand cursor on everything clickable, the mouse wheel scrolls the chat at the native rate, and you can no longer "swipe" by accident with the mouse
- onboarding opens its settings as windows, the backup import sits centred in its window, and the background grain no longer turns into blocks

## logs and crashes

- **More → Logs & crashes**: the app keeps a log of every launch and offers to send a report after a crash. API keys are masked in the logs, and the OS, device model and hardware are recorded. everything stays on the device until you share it yourself

## other

- on Android the notification icon is an envelope again, not a tiny swirl
