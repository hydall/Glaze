## translation

- the API settings' Agents tab got a **Translation** slot. translate with the chat model or a dedicated service: **DeepL, Google, Yandex or LibreTranslate**
- every message now has a **translate button** next to its menu (once you've turned the translator on). the translation is display-only: the prompt, the editor and copy still get the original
- the composer's **Translate** action translates your draft into the roleplay language (and can undo it). it can be pinned to the composer row like any other action
- **auto-translation**: of your own messages when sending (the model then gets the translation) and of character messages when receiving (on screen only, the model keeps the original)
- the model's translation prompt is editable and can be saved as presets

## guides and onboarding

- **screen guides**: the first time you open a tab (chat, characters, tools, API), it spotlights what's where and how to set it up. you can replay them from the menu. JanitorAI's closed-lorebook extractor also walks you through its steps on first open.

## chat

- when a reply was cut off because it **hit the output token cap** (Max Tokens) rather than because the model finished it, Glaze will tell you so
- Max Tokens can no longer exceed the context size, and if the preset doesn't fit into the context minus Max Tokens, the app says so and won't let you send the message

## characters and catalog

- characters have a new **Appearance** field. image generation sends it to models that can't take references (or when you pick it in the image-gen settings)
- **creator pages** for JanitorAI and Chub: tap the author to open their cards
- a redesigned **filter sheet**
- when a triggered lorebook hits JanitorAI's 120k-token cap, the trigger is split and re-run piece by piece in fresh chats, so big lorebooks no longer lose entries
- the "created by … on janitorai.com" credit is stripped from JanitorAI cards
- when JanitorAI keeps answering 401 (mostly because of a VPN), the catalog offers to **log in again** instead of just showing an error

## lorebooks

- **a new vector auto-indexing mode**: saved lorebooks are embedded in the background
- vector settings are always visible, and when embeddings aren't set up, the app explains why and opens the right tab

## backups and sync

- **Tavo backup import (.tbk) is back**: characters, personas, lorebooks, presets, chats with swipes and memory, API and regex
- cloud sync now actually syncs **API keys** (when that's on) and carries the chat layout

## presets and API

- switching protocols rebuilds the URL properly: Gemini's `v1beta` no longer sticks to other endpoints
- built-in presets show up in the list on the very first launch, not after a restart
- preset blocks that use variables have their SET/GET badges back
- **extBlocks** honour the block's context list and `apply_regex`, keep images out of the context and expand `{{persona}}`

## look

- **device theme**: a theme now has a type (dark, light or same as device), and settings have "Follow device theme" with separate themes for the light and dark modes

## logs and crashes

- **More → Logs & crashes**: the app keeps a log of every launch and offers to send a report after a crash. API keys are masked in the logs, and the OS, device model and hardware are recorded. everything stays on the device until you share it yourself

on top of that, a great many rough edges and small things got fixed, the interface included, on both phone and desktop
