a small hotfix for 0.8.0: mostly fixing what broke, plus a few small things on top

## upgrading from 0.7

- upgrading the database from older versions (0.7.x) **no longer crashes** on launch. the upgraded database also gets back the indexes that used to get lost along the way

## chat

- **guided impersonation** works again: the checkmark on the send button no longer ignores taps, and the typed guidance doesn't get lost
- the back-to-top button moved to the bottom-right corner, **right above the scroll-down button**

## characters and catalog

- the character sheet's menu (three dots) got **export**: PNG, JSON or ZIP, same as in the list
- the sheet's **Images** tab got tidied up: a neat grid, an image count and a proper placeholder when there are no images yet
- **JannyAI** opens cards again: the site put up a Cloudflare check, which we now pass through a built-in WebView

## pics

- errors when loading the model list or checking the connection now show up in a **readable block** instead of a wall of red text

## other

- the language block in the **Shino** preset now asks for English instead of Russian (it's still off by default)
- **Linux**: the build builds and runs again on an up-to-date Arch, which no longer has `libwpe`
- the `staging` build channel is gone: only stable and nightly remain
