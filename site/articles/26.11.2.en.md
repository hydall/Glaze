## embeddings

- on the embeddings screen you can rebuild the index for **selected sources only**: pick the ones you need and start the rebuild

## pictures

- NovelAI settings for V4.5 and V5 get a **Precise Reference** section: the default reference type (`Character & Style`, `Character`, `Style`, plus `Outfit` on V5), `Strength`, and `Fidelity` on V4.5 or `Prefer same outfit` on V5
- `Strength` goes up to 1 on V4.5 and 5 on V5; `Strength` and `Fidelity` accept negative values
- each reference library entry can pick **its own type** (`As in settings` by default), so a character and a style reference can be mixed in one request; a type the model does not offer falls back to the default
- on V5 references work in Full and Curated
- V4.5 reference images fit the closest canvas by aspect ratio; black stays around the image and behind fully clear pixels. V5 scales to the closest supported size
