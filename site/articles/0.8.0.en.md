once again the biggest update yet, and once again a pile of goodies

## the desktop layout is back

I reworked the desktop layout yet again, trying to make it more convenient and more familiar

- **three columns**, like in the old Vue interface. everything that went missing in the move is done
- **floating windows**: move them, resize them, maximize them, minimize them to the dock, keep several open side by side and switch between them with **Ctrl+Tab**
- everything that slides up from the bottom on a phone opens as a **neat centred window** on desktop, not as a strip across the whole screen
- a proper layout for **tablets**, in both portrait and landscape

## chat

- **the button row under the message field is now customizable**: drop what you don't need, reorder the rest and pin any tool, quick reply or action to it. the drawer under the chat got more convenient overall, too.
- "Actions" and the fullscreen message editor got buttons for **quickly inserting `*asterisks*` and "quotes"**.
- the **prompt inspector** was reworked: it shows a request timeline, what went to the model and which tokenizer counted it.
- you can **attach up to four images** to one message, straight from the clipboard too
- a **context card** appeared under the chat header: you can see at a glance which memories and lorebook entries make it into the request, which got cut, and why
- there's now a "back to top" button and a confirmation before deleting messages (it can be switched off in the settings)

## interface

- everything that has presets now has **folders** too: arrange and sort things however you like, hide the ones you don't want, and so on.
- the **tools grid** can be laid out however you like: hide, enlarge or shrink tiles to put everything exactly where you want it.
- there are so many interface changes that we can't count them anymore. every screen, window, sheet and switch now follows one style; clutter is gone, unclear things are labelled, awkward things are moved. in short, **the app should be noticeably more convenient and easier to understand**. and if something still bugs you, tell me and I'll keep tweaking

## catalog

- **Chub**: you can connect your account. there are native search filters (NSFL, "with a lorebook only", "with alternate greetings only" and a bunch more) and a personal **Timeline** feed
- **DataCat** moved to the official API, so it's more stable and sorts properly (all time / week / day)
- **JanitorAI**: the extraction settings are merged into one ("locally" or "via DataCat"), and the filters now offer popular custom tags
- **import by link** now understands Pygmalion, RisuAI, Perchance, AICharacterCards, JannyAI and Chub
- **blurring NSFW/NSFL images**: optional, and you can lift it right in the preview. it doesn't remove characters from the results, it only hides the pictures
- the first time you open the catalog, a short guide shows up. you can bring it back later from the provider settings

## pics

- native **NovelAI** (V3, V4, V4.5, V5), including V4.5 character references
- **ComfyUI** with its own workflow library and import from "Export Workflow (API)"
- **xAI Imagine**, **OpenRouter**, **Electron Hub**, **A1111**
- Naistera fixes
- a **style library** with negative prompts, and any width and height you like, so you don't have to juggle prompts and presets

## presets and API

- a new built-in preset — **NoriMyn**
- the default preset for a fresh install, **Shino**, is updated to the latest version
- **tokenizers for every model**: Claude, Gemini, Llama, Qwen, DeepSeek, Mistral and more. tokens are now counted for real instead of eyeballed. by default the tokenizer is picked from the model name
- in the API settings, history trimming can be switched to a mode that **plays nice with caching** (more on that in the app itself)
- custom endpoints got **SillyTavern-style prompt post-processing** (merge / semi / strict / single)
- **NoAssistant** support is here (it will keep improving)
- **Responses API** was added as a protocol of its own
- new connections now start with lean generation settings, and API settings can be reset to their defaults

## Linux

Linux folks aren't forgotten either: Glaze now ships in more package formats, and the chat moved to a different WebView, so **the chat actually works on Linux now**.

## JAR: done and dusted

in 0.7.0 JAR had only just moved into Glaze and was "still in development". now it's **finished and fully built into Glaze**: extracting cards and lorebooks from JanitorAI, private ones included, works right from the catalog, no third-party tools needed

## extBlocks are no longer an experiment

extBlocks are finished: blocks from the original Tavern extension now **import almost without losses**. we'll keep an eye on what else we can bring over

## Studio/Agents

I'm really unhappy with how Studio turned out, and I have neither the energy nor the will to fix the current implementation, so it's **going in for a complete rework**. expect it after 1.0

## under the hood

- **a great many small, nasty bugs were fixed**: jumping scroll, lost swipes, stuck toasts, vanishing settings, duplicate messages and the rest of the critters that spoiled life a little bit every day
- the app behaves much more sanely: glass, blur and sheets got a lot lighter, older phones included — and on some of them Glaze launches at all now, thanks to the **APK build for 32-bit processors**.
- mass-importing hundreds of cards and restoring a backup no longer crash the app, and exporting a backup with huge chats no longer eats all the memory
- we fixed cloud sync, notifications on every platform, and races when sending and deleting messages
