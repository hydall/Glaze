Плагин получает только то, что перечислил в `permissions` в манифесте, и только то, что включил пользователь. После установки все разрешения выключены: пользователь видит список и включает то, что готов дать. Любое разрешение можно отобрать в любой момент на странице плагина.

## Список

| Разрешение | Что даёт |
|---|---|
| `composer` | Поле ввода: читать, менять и отправлять текст (`glaze.composer`); хуки `send:*`. |
| `messages` | Открытый чат: его сообщения и варианты, книгу памяти, настройки чата (`glaze.messages`, `glaze.memory`, `glaze.chats.current`); события `chat:*` и `message:*`. |
| `variables` | Собственные переменные плагина: для чата, для сообщения и глобальные. |
| `variables.shared` | Общие переменные `shared`, которые все плагины читают и пишут вместе. |
| `files` | Собственные файлы плагина (`glaze.files`), импорт и экспорт через файлы. |
| `generate` | Генерация текста через подключение чата (`glaze.generate`); хуки `generation:*`. |
| `images` | Генерация картинок по настройкам пользователя (`glaze.images.generate`). Спрашивает. |
| `network` | Доступ в интернет. См. [Сеть](#docs/plugins-permissions/сеть). |
| `library.read.<вид>` | Чтение библиотеки: персонажи, персоны, пресеты, лорбуки, regex-скрипты или темы. |
| `library.create.<вид>` | Добавление в библиотеку. Спрашивает. |
| `library.update.<вид>` | Изменение библиотеки. Спрашивает. |
| `library.delete.<вид>` | Удаление из библиотеки. Спрашивает. |
| `chats.read` | Другие чаты: поиск, чтение, открытие. |
| `chats.create` | Создание, копирование и импорт чатов. Спрашивает. |
| `chats.update` | Изменение других чатов. Спрашивает. |
| `chats.delete` | Удаление чатов. Спрашивает. |

`<вид>` — одно из `characters`, `personas`, `presets`, `lorebooks`, `regex`, `themes`. Просите только то, чем пользуетесь: `library.read.lorebooks`, а не всю библиотеку.

Короткие формы: `library.read` (а также `create`, `update`, `delete`) означает это действие для всех видов.

## Разрешения, которые спрашивают

Разрешения с пометкой «Спрашивает» пользователь подтверждает при каждом вызове: Glaze показывает окно с именем плагина и тем, что он хочет сделать, и пользователь выбирает **Разрешить один раз**, **Разрешать всегда** или **Запретить**. «Запретить» выключает разрешение. На странице плагина каждое из них можно поставить в положение «Спрашивать», «Всегда» или «Запрещено».

Вызов ждёт ответа. Если окно закрыли, вызов отклоняется.

## Отказы

Вызов, который плагину не разрешён, завершается ошибкой с `code` равным `permission_denied`:

```js
try {
  await glaze.lorebooks.list();
} catch (e) {
  if (e.code === 'permission_denied') {
    // подскажите пользователю, что включить, или обойдитесь без этого
  }
}
```

Пользователь видит уведомление с именем плагина, один раз на каждое действие. Отказавший плагин больше не спрашивают: если разрешение нужно, пользователь включает его сам. Каждый вызов и ответ на него попадают в историю запросов плагина на его странице.

Методов, разрешения для которых манифест не просит, в `glaze` нет вовсе. Методы разрешений, которые пользователь выключил, есть, но завершаются ошибкой.

Хукам и событиям тоже нужны разрешения. Плагин без `composer` не получает `send:*`, без `generate` — `generation:*`, без `messages` — `chat:*` и `message:*`.

## Сеть

Без разрешения `network` у плагина совсем нет интернета: его фреймы не могут ничего загрузить извне, а `glaze.net.fetch` отклоняется. Если плагин просит это разрешение, пользователь ставит его на странице плагина в один из трёх режимов:

| Режим | Куда плагин может обращаться |
|---|---|
| Выключен | Никуда. |
| Только разрешённые | Только к адресам, которые включил пользователь. Адреса из `hosts` в манифесте уже есть в списке, но выключены. |
| Любые адреса | Куда угодно в интернете. |

Перечислите свои адреса в манифесте:

```json
"permissions": ["network"],
"hosts": ["api.example.com", "*.cdn.example.com"]
```

`*.example.com` охватывает поддомены, но не сам `example.com`.

Правила действуют на всё, что делает плагин: `fetch`, `XMLHttpRequest`, `WebSocket`, `EventSource`, картинки, скрипты и стили из интернета и запросы через `glaze.net.fetch`. Без переключателя локальной сети работает только https в интернете. Локальная сеть (localhost, `192.168.*`, `*.local` и так далее) и незащищённый http включаются отдельным переключателем, по умолчанию он выключен. WebRTC доступен только в режиме «Любые адреса».

На странице плагина перечислены все адреса, с которых его фреймы загружали данные или которые были заблокированы. В режиме «Только разрешённые» пользователь может прямо там разрешить или запретить каждый из них.

## Запросы через приложение

`glaze.net.fetch` отправляет запрос из приложения, а не из фрейма плагина. Правила кросс-доменных запросов страницы (CORS) на него не действуют, поэтому плагин может обращаться к API, которое не пускает браузеры, без своего сервера-посредника. Правила доступа плагина в интернет действуют как обычно. Подробнее: [glaze.net](#docs/plugins-api/glaze-net).

## Безопасность

Изолированные фреймы и разрешения ограничивают, что может сделать плагин, но не гарантируют полную безопасность. Ставьте плагины только от авторов, которым доверяете, а у своих пользователей просите только то, что плагину действительно нужно.
