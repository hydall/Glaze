## Один плоский объект

Тема Glaze — это один JSON-объект. Все поля необязательны; если поля нет,
остаётся значение по умолчанию. Неизвестные поля игнорируются, поэтому файл
от более новой версии всё равно импортируется.

Цвета записываются как `#RRGGBB` или `#AARRGGBB` (альфа в начале). Размеры и
радиусы — числа в логических пикселях. Картинка или файл шрифта — это
`data:`-URI; редактор записывает их сам, когда вы выбираете файл.

| Поле | Тип | Значение |
|------|-----|----------|
| `name` | строка | Показывается в списке и становится именем файла при экспорте. |
| `author` | строка | Автор, свободный текст. |
| `themeMode` | `dark`, `light`, `system` | В какой яркости рисуется палитра. |
| `accentColor` | цвет | Акцент кнопок, ссылок и выделений. По умолчанию `#C42A4A`. |
| `id` | строка | При импорте игнорируется; Glaze назначает новый. |

## Интерфейс приложения

| Поле | По умолчанию | Значение |
|------|--------------|----------|
| `uiColor` | вычисляется | Основной цвет поверхностей приложения. |
| `uiTextColor` | вычисляется | Основной текст. |
| `uiTextGrayColor` | вычисляется | Второстепенный текст и подсказки. |
| `bgColor` | вычисляется | Фон приложения за всеми экранами. |
| `bgImage` | нет | Картинка фона приложения как `data:`-URI. |
| `bgDim` | `0.15` | Чёрная вуаль поверх фоновой картинки, `0`–`1`. |
| `bgBlur` | `0` | Размытие фоновой картинки в пикселях. |
| `elementOpacity` | `0.8` | Непрозрачность стеклянных поверхностей и пузырей чата, `0`–`1`. |
| `elementBlur` | `12` | Размытие фона у этих поверхностей в пикселях. |
| `borderWidth` | `1` | Толщина границ карточек и поверхностей. |
| `borderColor` | вычисляется | Цвет границ. |
| `borderOpacity` | `0.1` | Прозрачность границ, `0`–`1`. |
| `cornerScale` | `1` | Множитель скруглений кнопок, карточек и шторок; `0` делает их прямыми, `1` — обычный вид. |
| `avatarRoundness` | `1` | Форма аватара: `1` — круг, `0` — квадрат. |
| `noiseOpacity` | `0.03` | Зерно поверх интерфейса приложения. |
| `noiseIntensity` | `0.8` | Сила зерна. |
| `bgNoiseOpacity` | `0.03` | Зерно поверх фона чата. |
| `bgNoiseIntensity` | `0.4` | Сила зерна чата. |

## Макет и настройки темы

| Поле | Значение |
|------|----------|
| `layout` | Шаблоны, стили и объявление экрана «Чат». Описано в разделе [Макет чата](#info/themes-layouts). |
| `themeValues` | Значения, которые читатель выбрал в собственных настройках темы. Экспорт их записывает; вручную их задавать почти никогда не нужно. |

## Тема с фоном

```json
{
  "name": "Paper",
  "themeMode": "light",
  "accentColor": "#8A5A3B",
  "uiColor": "#F4EBDD",
  "bgColor": "#EAE0CF",
  "bgImage": "data:image/png;base64,...",
  "bgDim": 0.05,
  "chatBgMode": "color",
  "chatBgColor": "#F4EBDD",
  "charTextColor": "#3A312A",
  "userTextColor": "#3A312A"
}
```

Редактор пишет те же поля и показывает превью, поэтому обычно тему собирают
там и экспортируют готовый результат. Редактировать JSON вручную удобнее
всего ради макета, который поставляется архивом.
