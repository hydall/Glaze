`plugin.json` лежит в корне пакета и описывает плагин: как он называется, что просит и где появляется. Glaze проверяет манифест при импорте и не принимает пакет с ошибкой в манифесте или без файла, на который манифест ссылается.

## Основные поля

| Поле | Обязательно | Что это |
|---|---|---|
| `format` | да | Версия формата манифеста. Сейчас `1`. |
| `id` | да | Уникальный id: строчные латинские буквы, цифры, `.`, `_`, `-`, до 128 символов, например `author.plugin-name`. Не меняйте его между версиями: обновления сопоставляются по `id`. |
| `name` | да | Название, которое видит пользователь. Текст или ключ перевода. |
| `version` | да | Версия в формате SemVer: `1.0.0`, `1.2.0-beta.1`. |
| `author` | нет | Автор. Обновление от другого автора ставится как отдельный плагин. |
| `description` | нет | Краткое описание. Текст или ключ перевода. |
| `releaseNotes` | нет | Что изменилось в этой версии; показывается на странице плагина. |
| `icon` | нет | Путь к картинке в пакете, она показывается обложкой на странице плагина. |
| `main` | нет | Путь к основному скрипту. Обязателен, если у плагина есть действия. |
| `permissions` | нет | Что просит плагин. См. [Разрешения и сеть](#info/plugins-permissions). |
| `hosts` | нет | Адреса в интернете, которые нужны плагину: `api.example.com` или `*.example.com`. |
| `locales` | нет | Файлы переводов, см. ниже. |
| `minGlazeVersion` | нет | Минимальная версия Glaze, под которую написан плагин. Пока Glaze её не проверяет. |
| `contributes` | нет | Что плагин добавляет в интерфейс: действия, панели, обработчики файлов, настройки. |

## Переводимый текст

Везде, где манифест принимает текст для пользователя (`name`, `description`, подписи действий, настройки), можно написать строку или ключ из файлов перевода:

```json
"name": { "t": "plugin.name" }
```

Переводы перечисляются в `locales`:

```json
"locales": {
  "default": "en",
  "files": {
    "en": "locales/en.json",
    "ru": "locales/ru.json"
  }
}
```

Файл перевода — плоский объект из ключей и строк:

```json
{
  "plugin.name": "Счётчик сообщений",
  "action.count": "Посчитать сообщения",
  "toast.count": "Сообщений в чате: {count}"
}
```

Glaze берёт язык интерфейса пользователя, затем другой вариант того же языка, затем английский, затем `default`. Если ключа нет нигде, показывается сам ключ. Те же файлы доступны в коде через `glaze.plugin.i18n` (см. [справочник API](#info/plugins-api/glaze-plugin)).

## Действия

Действия — это кнопки, которые плагин добавляет в чат. У каждого есть `id` (уникальный в своём списке), `label` и при желании `icon` (путь в пакете).

```json
"contributes": {
  "composerActions": [{ "id": "tone", "label": "Сменить тон" }],
  "toolsActions": [{ "id": "count", "label": "Посчитать сообщения" }],
  "messageActions": [{ "id": "rate", "label": "Оценить", "icon": "icons/star.svg", "role": "character" }]
}
```

| Список | Где появляется |
|---|---|
| `composerActions` | Вкладка «Действия» в панели чата, которая открывается из поля ввода. |
| `toolsActions` | Вкладка «Инструменты» в той же панели. |
| `messageActions` | Круглая кнопка внизу последнего сообщения. `role` — на чьих сообщениях она появляется: `character` (по умолчанию), `user` или `any`. Без иконки на кнопке первая буква подписи. |

Нажатие вызывает обработчик, который основной скрипт зарегистрировал для этого `id`; см. [Хуки, действия и панели](#info/plugins-runtime/действия).

## Панели

Панель — это HTML-страница плагина, которая показывается в чате.

```json
"panels": [
  { "id": "hud", "src": "hud.html", "placement": "chat" },
  { "id": "stats", "src": "stats.html", "placement": "message", "role": "character", "position": "last", "slot": "end" }
]
```

| Поле | Что это |
|---|---|
| `id` | Id панели. |
| `src` | Путь к HTML панели в пакете. |
| `placement` | `chat` — поверх всего чата; `message` — внутри сообщений. |
| `slot` | `start` или `end` (по умолчанию): до или после содержимого. |
| `role` | Для панелей в сообщениях: только в сообщениях `user` или только `character`. |
| `position` | Для панелей в сообщениях: только в первом (`first`) или только в последнем (`last`) сообщении. |

Как располагаются панели и как они подгружают файлы пакета: [Хуки, действия и панели](#info/plugins-runtime/панели).

## Обработчики файлов

Обработчик файлов превращает прикреплённый файл в текст для сообщения. Например, достаёт текст из `.docx` или `.pdf`.

```json
"fileHandlers": [
  { "id": "docx", "extensions": ["docx"], "mimeTypes": [], "scripts": ["docx.js"] }
]
```

`extensions` (без точки) и `mimeTypes` задают, какие файлы он берёт; нужно хотя бы одно из двух. `scripts` загружаются только для работы этого обработчика; если список пуст, обработчик регистрирует основной скрипт. Регистрация в коде: [Хуки, действия и панели](#info/plugins-runtime/обработчики-файлов).

## Настройки

`settings` описывает форму на странице плагина в **Инструменты → Плагины**. Glaze рисует её, хранит значения и передаёт их плагину. Поля идут в том порядке, в каком перечислены.

```json
"settings": [
  { "type": "toggle", "key": "enabled", "label": "Включено", "default": true },
  { "type": "select", "key": "mode", "label": "Режим", "default": "short",
    "options": [{ "value": "short", "label": "Коротко" }, { "value": "long", "label": "Подробно" }] },
  { "type": "slider", "key": "count", "label": "Количество", "min": 1, "max": 10, "step": 1, "default": 3 },
  { "type": "text", "key": "name", "label": "Имя", "description": "Используется в ответах" },
  { "type": "textarea", "key": "prompt", "label": "Промпт" },
  { "type": "note", "text": "Изменения применятся при следующем открытии чата.", "icon": "info" },
  { "type": "divider" }
]
```

| `type` | Поля |
|---|---|
| `toggle` | `key`, `label`, `description`, `default` (true/false). |
| `select` | `key`, `label`, `description`, `default`, `options`: строки или `{ value, label }`. |
| `slider` | `key`, `label`, `description`, `default`, `min`, `max`, `step`. |
| `text`, `textarea` | `key`, `label`, `description`, `default`. |
| `note` | `text`, `icon`: `info` или `warning`. Пояснение, ничего не хранит. |
| `divider`, `group` | Делит форму на части. |

`label`, `description`, `text`, подписи вариантов и текстовые значения по умолчанию могут быть ключами перевода. Значения читаются через `glaze.plugin.settings.get(key)`. Когда пользователь меняет настройку, фреймы плагина перезапускаются с новыми значениями.

## Полный пример

```json
{
  "format": 1,
  "id": "example.mood",
  "name": { "t": "plugin.name" },
  "version": "1.2.0",
  "author": "you",
  "description": { "t": "plugin.description" },
  "icon": "icon.png",
  "main": "main.js",
  "permissions": ["messages", "variables", "generate", "network"],
  "hosts": ["api.example.com"],
  "locales": {
    "default": "en",
    "files": { "en": "locales/en.json", "ru": "locales/ru.json" }
  },
  "contributes": {
    "toolsActions": [{ "id": "reset", "label": { "t": "action.reset" } }],
    "panels": [{ "id": "mood", "src": "mood.html", "placement": "message", "role": "character", "position": "last" }],
    "settings": [
      { "type": "toggle", "key": "auto", "label": { "t": "settings.auto" }, "default": true }
    ]
  }
}
```
