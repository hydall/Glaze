`plugin.json` лежит в корне пакета и описывает плагин: как он называется, что просит и где появляется. Glaze проверяет манифест при импорте и не принимает пакет с ошибкой в манифесте или без файла, на который манифест ссылается.

## Основные поля

| Поле | Обязательно | Что это |
|---|---|---|
| `format` | да | Версия формата манифеста. Сейчас `1`. |
| `id` | да | Уникальный id: строчные латинские буквы, цифры, `.`, `_`, `-`, до 128 символов, например `author.plugin-name`. Не меняйте его между версиями: обновления сопоставляются по `id`. |
| `name` | да | Название, которое видит пользователь. Текст или ключ перевода. |
| `version` | да | Версия в формате SemVer: `1.0.0`, `1.2.0-beta.1`. |
| `author` | нет | Автор. Обновление от другого автора ставится как отдельный плагин. |
| `description` | нет | Краткое описание. Текст или ключ перевода. |
| `releaseNotes` | нет | Что изменилось в этой версии; показывается на странице плагина. |
| `icon` | нет | Путь к картинке в пакете: обложка вкладки «Информация» на странице плагина, на весь экран позади названия и описания. |
| `main` | нет | Путь к основному скрипту. Обязателен, если у плагина есть действия. |
| `permissions` | нет | Что просит плагин. См. [Разрешения и сеть](#info/plugins-permissions). |
| `hosts` | нет | Адреса в интернете, которые нужны плагину: `api.example.com` или `*.example.com`, каждый строкой или `{ "host", "description" }`. См. [Сеть](#info/plugins-permissions/сеть). |
| `locales` | нет | Файлы переводов, см. ниже. |
| `minGlazeVersion` | нет | Минимальная версия Glaze, под которую написан плагин. Пока Glaze её не проверяет. |
| `contributes` | нет | Что плагин добавляет в интерфейс: действия, панели, обработчики файлов, настройки и их вкладки. |

## Переводимый текст

Везде, где манифест принимает текст для пользователя (`name`, `description`, подписи действий, настройки, названия вкладок, описания адресов), можно написать строку или ключ из файлов перевода:

```json
"name": { "t": "plugin.name" }
```

Переводы перечисляются в `locales`:

```json
"locales": {
  "default": "en",
  "files": {
    "en": "locales/en.json",
    "ru": "locales/ru.json"
  }
}
```

Файл перевода — плоский объект из ключей и строк:

```json
{
  "plugin.name": "Счётчик сообщений",
  "action.count": "Посчитать сообщения",
  "toast.count": "Сообщений в чате: {count}"
}
```

Glaze берёт язык интерфейса пользователя, затем другой вариант того же языка, затем английский, затем `default`. Если ключа нет нигде, показывается сам ключ. Те же файлы доступны в коде через `glaze.plugin.i18n` (см. [справочник API](#info/plugins-api/glaze-plugin)).

## Действия

Действия — это кнопки, которые плагин добавляет в чат. У каждого есть `id` (уникальный в своём списке), `label` и при желании `icon` (путь в пакете).

```json
"contributes": {
  "composerActions": [{ "id": "tone", "label": "Сменить тон" }],
  "toolsActions": [{ "id": "count", "label": "Посчитать сообщения" }],
  "messageActions": [{ "id": "rate", "label": "Оценить", "icon": "icons/star.svg", "role": "character" }]
}
```

| Список | Где появляется |
|---|---|
| `composerActions` | Вкладка «Действия» в панели чата, которая открывается из поля ввода. |
| `toolsActions` | Вкладка «Инструменты» в той же панели. |
| `messageActions` | Круглая кнопка внизу последнего сообщения. `role` — на чьих сообщениях она появляется: `character` (по умолчанию), `user` или `any`. Без иконки на кнопке первая буква подписи. |

В панели чата иконка в SVG окрашивается как собственные иконки приложения, другие картинки сохраняют свои цвета. Без иконки на карточке стандартная. Под подписью на каждой карточке плагина — значок пазла и название плагина.

Нажатие вызывает обработчик, который основной скрипт зарегистрировал для этого `id`; см. [Хуки, действия и панели](#info/plugins-runtime/действия).

## Панели

Панель — это HTML-страница плагина, которая показывается в чате.

```json
"panels": [
  { "id": "hud", "src": "hud.html", "placement": "chat" },
  { "id": "stats", "src": "stats.html", "placement": "message", "role": "character", "position": "last", "slot": "end" }
]
```

| Поле | Что это |
|---|---|
| `id` | Id панели. |
| `src` | Путь к HTML панели в пакете. |
| `placement` | `chat` — поверх всего чата; `message` — внутри сообщений. |
| `slot` | `start` или `end` (по умолчанию): до или после содержимого. |
| `role` | Для панелей в сообщениях: только в сообщениях `user` или только `character`. |
| `position` | Для панелей в сообщениях: только в первом (`first`) или только в последнем (`last`) сообщении. |

Как располагаются панели и как они подгружают файлы пакета: [Хуки, действия и панели](#info/plugins-runtime/панели).

## Обработчики файлов

Обработчик файлов превращает прикреплённый файл в текст для сообщения. Например, достаёт текст из `.docx` или `.pdf`.

```json
"fileHandlers": [
  { "id": "docx", "extensions": ["docx"], "mimeTypes": [], "scripts": ["docx.js"] }
]
```

`extensions` (без точки) и `mimeTypes` задают, какие файлы он берёт; нужно хотя бы одно из двух. `scripts` загружаются только для работы этого обработчика; если список пуст, обработчик регистрирует основной скрипт. Регистрация в коде: [Хуки, действия и панели](#info/plugins-runtime/обработчики-файлов).

## Настройки

`settings` описывает форму на странице плагина в **Инструменты → Плагины**. Glaze рисует её, хранит значения и передаёт их плагину. Поля идут в том порядке, в каком перечислены, все на одной вкладке **Настройки**, если плагин не разложил их по [вкладкам](#info/plugins-manifest/вкладки).

```json
"settings": [
  { "type": "toggle", "key": "enabled", "label": "Включено", "default": true },
  { "type": "select", "key": "mode", "label": "Режим", "default": "short",
    "options": [{ "value": "short", "label": "Коротко" }, { "value": "long", "label": "Подробно" }] },
  { "type": "slider", "key": "count", "label": "Количество", "min": 1, "max": 10, "step": 1, "default": 3 },
  { "type": "text", "key": "name", "label": "Имя", "description": "Используется в ответах" },
  { "type": "textarea", "key": "prompt", "label": "Промпт" },
  { "type": "note", "text": "Изменения применятся при следующем открытии чата.", "icon": "info" },
  { "type": "divider" },
  { "type": "apiPreset", "key": "summary", "label": "Пересказы", "description": "Подойдёт дешёвая модель" },
  { "type": "imagePreset", "key": "photos", "label": "Фото" }
]
```

| `type` | Поля |
|---|---|
| `toggle` | `key`, `label`, `description`, `default` (true/false). |
| `select` | `key`, `label`, `description`, `default`, `options`: строки или `{ value, label }`. |
| `slider` | `key`, `label`, `description`, `default`, `min`, `max`, `step`. |
| `text`, `textarea` | `key`, `label`, `description`, `default`. |
| `note` | `text`, `icon`: `info` или `warning`. Пояснение, ничего не хранит. |
| `divider`, `group` | Делит форму на части. |
| `apiPreset` | `key`, `label`, `description`. Подключение к API и модель для одной из функций плагина. |
| `imagePreset` | `key`, `label`, `description`. Сервис картинок и стиль для одной из картинок плагина. |

У любого поля может быть ещё `tab`, см. ниже.

`label`, `description`, `text`, подписи вариантов и текстовые значения по умолчанию могут быть ключами перевода. Значения читаются через `glaze.plugin.settings.get(key)`. Когда пользователь меняет настройку, фреймы плагина перезапускаются с новыми значениями.

### Пресеты API

Плагин часто генерирует в нескольких местах, и каждому может быть нужна своя модель: ответам в чате — сильная, фоновому разбору сцены — быстрая и дешёвая, фото — свой стиль, не как у остальных картинок. Для каждой такой функции объявите `apiPreset` (текст) или `imagePreset` (картинки) и назовите его в вызове:

```js
await glaze.generate(prompt, { preset: 'summary' });
await glaze.images.generate(prompt, { preset: 'photos' });
```

Каждый пресет рисуется на странице плагина отдельной группой с заголовком из `label` и описанием из `description`, с теми же строками, что и другие слоты API в Glaze:

- `apiPreset`: **Подключение API** и **Модель**;
- `imagePreset`: **Сервис картинок** и **Стиль картинок**. Сервис может быть как в настройках генерации или любым из настроенных там (NovelAI, Naistera и другие); картинка рисуется с ключом, моделью и параметрами этого сервиса из настроек картинок. Сервисы, которые рисуют через эндпоинт LLM, берут подключение открытого чата. Стиль может быть как в настройках генерации, «Без стиля» или одним из библиотеки стилей.

Пока пользователь ничего не выбрал, а также для вызовов без `preset`, Glaze берёт подключение открытого чата и настройки картинок, как раньше. Если выбранное подключение удалено, вызов идёт через подключение чата. `preset`, которого нет в манифесте или который объявлен для другого вида вызова, завершается ошибкой `unknown_preset`. Выбор Glaze хранит вместе с остальными настройками плагина; читать его плагину не нужно.

Настройки-пресеты появились в Glaze 0.9.0 (Nightly). Старые версии не знают этих типов и плагин не установят, поэтому укажите `minGlazeVersion`: `0.9.0`.

### Вкладки

У страницы плагина есть вкладки **Информация**, **Разрешения** и **Данные**; плагин с настройками добавляет свои между «Разрешениями» и «Данными». Без `settingsTabs` это одна вкладка **Настройки** со всеми полями. Чтобы разложить поля, перечислите до 10 вкладок в `contributes.settingsTabs` и укажите вкладку в `tab` у каждого поля:

```json
"contributes": {
  "settingsTabs": [
    { "id": "main", "label": "Основное" },
    { "id": "look", "label": { "t": "tabs.look" }, "icon": "icons/palette.svg" }
  ],
  "settings": [
    { "type": "toggle", "key": "auto", "label": "Запускать на каждый ответ", "default": true },
    { "type": "select", "key": "theme", "label": "Тема панели", "tab": "look", "options": ["light", "dark"] }
  ]
}
```

| Поле | Что это |
|---|---|
| `id` | Id вкладки, уникальный среди вкладок. |
| `label` | Название вкладки. Текст или ключ перевода. |
| `icon` | Необязательный путь к картинке в пакете; без него у вкладки стандартная иконка. |

Поле без `tab` попадает на первую вкладку. Если `tab` называет вкладку, которой нет в списке, `id` повторяется или вкладок больше 10, манифест считается ошибочным. Вкладка, на которой нет ни одного поля, не показывается. Пользователь переключает вкладки в меню под шапкой страницы.

Вкладки появились в Glaze 0.9.0 (Nightly); старые версии не знают `settingsTabs` и `tab` и показывают все поля на одной странице.

## Полный пример

```json
{
  "format": 1,
  "id": "example.mood",
  "name": { "t": "plugin.name" },
  "version": "1.2.0",
  "author": "you",
  "description": { "t": "plugin.description" },
  "icon": "icon.png",
  "main": "main.js",
  "minGlazeVersion": "0.9.0",
  "permissions": ["messages", "variables", "generate", "network"],
  "hosts": [{ "host": "api.example.com", "description": { "t": "hosts.api" } }],
  "locales": {
    "default": "en",
    "files": { "en": "locales/en.json", "ru": "locales/ru.json" }
  },
  "contributes": {
    "toolsActions": [{ "id": "reset", "label": { "t": "action.reset" } }],
    "panels": [{ "id": "mood", "src": "mood.html", "placement": "message", "role": "character", "position": "last" }],
    "settings": [
      { "type": "toggle", "key": "auto", "label": { "t": "settings.auto" }, "default": true }
    ]
  }
}
```
