Плагин добавляет возможности в чат Glaze: кнопки в панели чата, свои панели поверх чата или внутри сообщений, обработку сообщений перед отправкой и ответов после генерации, свои настройки. Плагины пишутся на HTML и JavaScript и общаются с приложением через API `glaze.*`.

## Как работает плагин

Каждый плагин работает в своём изолированном фрейме внутри чата. Он не видит страницу чата, другие плагины и данные приложения. Всё, что ему нужно, он просит через `glaze.*`, и приложение сверяет каждый вызов с разрешениями плагина.

Плагин получает только то, что указал в манифесте, и все разрешения сначала выключены: пользователь сам включает то, что готов дать. Некоторые действия, например изменение библиотеки или генерация картинок, вдобавок каждый раз спрашивают пользователя. Подробнее в разделе [Разрешения и сеть](#info/plugins-permissions).

## Пакет

Плагин — это файл `.glzp`: zip-архив, в корне которого лежит `plugin.json`. Остальное на ваше усмотрение:

```
my-plugin.glzp
├── plugin.json      манифест (обязателен)
├── main.js          основной скрипт
├── panel.html       панель
├── icon.png
└── locales/
    ├── en.json
    └── ru.json
```

Пути в манифесте указываются от корня архива, через прямой слеш. В пакете может быть до 2000 файлов и до 64 МБ в распакованном виде.

## Первый плагин

Этот плагин добавляет на вкладку «Инструменты» в панели чата действие, которое показывает, сколько в чате сообщений, и заменяет `:shrug:` в отправляемом сообщении на смайлик.

`plugin.json`:

```json
{
  "format": 1,
  "id": "example.counter",
  "name": "Счётчик сообщений",
  "version": "1.0.0",
  "author": "you",
  "description": "Считает сообщения в чате.",
  "main": "main.js",
  "permissions": ["messages", "composer"],
  "contributes": {
    "toolsActions": [
      { "id": "count", "label": "Посчитать сообщения" }
    ]
  }
}
```

`main.js`:

```js
glaze.plugin.onToolsAction('count', async () => {
  const count = await glaze.messages.count();
  glaze.ui.toast(`Сообщений в чате: ${count}`);
});

glaze.plugin.on('send:before', (event) => {
  event.text = event.text.replaceAll(':shrug:', '¯\\_(ツ)_/¯');
});
```

Запакуйте оба файла в zip (сами файлы, а не папку с ними) и переименуйте архив в `example.counter.glzp`.

## Установка и проверка

В Glaze откройте **Инструменты → Плагины → Импортировать плагин** и выберите файл. Glaze покажет, какие разрешения просит плагин; включите нужные. Откройте чат: действие появится на вкладке «Инструменты» в панели чата (кнопка рядом с полем ввода).

Чтобы обновить плагин, увеличьте `version` и импортируйте файл снова. Плагин сохранит свои данные и разрешения, которые дал пользователь; новые разрешения придут выключенными. Пакет с тем же `id`, но другим `author` ставится как новый плагин и данные старого не получает.

На странице плагина и в его меню в списке есть **Экспорт данных (JSON)** и **Импорт данных (JSON)**. В файл попадают настройки плагина, его `localStorage`, переменные (общие, по чатам и по сообщениям) и файлы `global` и чатов в base64; разрешения остаются на устройстве. Импорт заменяет данные плагина, а не дополняет их, и спрашивает подтверждение. Сначала проверяется весь файл: файл другого плагина, более новой версии Glaze или сверх лимитов плагина ничего не меняет. Переменные чатов, которых нет на устройстве, пропускаются. Работает для любого плагина, со стороны плагина ничего не нужно (Glaze 0.9.0 Nightly).

Что помогает при разработке:

- На странице плагина в **Инструменты → Плагины** есть его разрешения, настройки, журнал сети и история запросов: что плагин просил и разрешили ли ему.
- Запросы плагина (`glaze.generate`, `glaze.net.fetch`, `fetch` в его фреймах) видны в инспекторе промпта чата, на вкладке «Запросы».
- Запрещённый вызов завершается ошибкой с `code` равным `permission_denied`, а пользователь один раз видит уведомление.

## Расширения Tavo

Glaze также умеет ставить расширения Tavo (файлы `.tpg` и ссылки из Tavo Hub): они работают через слой совместимости. Как писать такие расширения, описано в [документации Tavo](https://docs.tavoai.dev/en/guides/plugin-development/). Новые плагины для Glaze лучше писать в формате, описанном здесь: он даёт больше возможностей и позволяет пользователю выдавать точные разрешения.
