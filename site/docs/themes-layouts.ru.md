## Что заменяет макет

Тема без макета меняет только цвета и шрифты. Макет идёт дальше: он решает,
где стоят части сообщения, что их окружает и как выглядят шапка чата, поле
ввода и ящик.

Сами части по-прежнему строит приложение. Шаблон выбирает, где они
появятся, поэтому живые обновления продолжают работать: новый свайп,
количество токенов или смена имени доходят до элемента, который поставил
шаблон.

HTML-редактора внутри приложения нет. Макеты пишут в файле темы и
импортируют.

## Объект layout

В архиве темы каждую часть можно держать в своём файле:

```json
{
  "name": "Cards",
  "accentColor": "#C42A4A",
  "layout": {
    "message": "layout/message.html",
    "css": "layout/chat.css",
    "contentCss": "layout/content.css",
    "settings": "settings.json",
    "chrome": {
      "header": "layout/header.html",
      "composer": "layout/composer.html",
      "card": "layout/card.html",
      "tab": "layout/tab.html",
      "css": "layout/chrome.css"
    }
  }
}
```

Каждое значение — либо путь внутри архива, либо сами разметка и CSS. Если
путь не найден, он игнорируется, и эта часть остаётся встроенной. Размер
одной части — не больше 256 КиБ.

Есть и плоская запись: `message`, `css`, `contentCss`, `header`,
`composer`, `drawerCard`, `drawerTab` и `chromeCss` могут лежать прямо в
`layout`; для частей хрома это альтернатива объекту `chrome`. У JSON-пресета,
экспортированного приложением, все части уже развёрнуты внутрь пресета,
поэтому он импортируется без архива.

| Часть | Что рисует |
|-------|------------|
| `message` | Каждое сообщение. |
| `css` | Страницу чата: область прокрутки, разделители, отступы сообщений. |
| `contentCss` | Внутри тела каждого сообщения, где рисуется Markdown. |
| `header` | Шапку чата. |
| `composer` | Поле ввода. |
| `card` | Содержимое каждой карточки в ящике чата. |
| `tab` | Содержимое каждой вкладки ящика. |
| `chromeCss` | Хром: шапку, поле ввода и ящик. |
| `settings` | Собственный экран «Чат» темы в редакторе. |

## Синтаксис шаблонов

| Синтаксис | Значение |
|-----------|----------|
| `{{ name }}` | Значение или часть значения атрибута. |
| `g-if="cond"` | Рисовать элемент, только пока условие истинно. |
| `g-else-if="cond"`, `g-else` | Ветки после `g-if`. |
| `g-each="pins" g-as="pin"` | Повторить элемент для каждого элемента списка. |
| `<g-part name="content"></g-part>` | Поставить сюда одну из частей приложения. |
| `<g-icon name="search">` | Именованная иконка из встроенного набора. |
| `<g-icon value="{{icon}}">` | Иконка, имя которой приходит из данных. |
| `g-action="regenerate"` | Нажатие выполняет это действие чата. |

Выражения — это пути (`swipe.total`), литералы, `!`, `==`, `!=`, `<`, `<=`,
`>`, `>=`, `&&`, `||` и `a ? b : c`. Внутри `g-each` поля элемента доступны
без префикса (`{{label}}`) и через его имя (`{{pin.label}}`); `{{index}}` —
позиция.

Разметка ограничена текстовыми и layout-элементами: `div`, `span`, `p`,
заголовки, списки, `table`, `button`, `img`, `svg` и его фигуры. `script`,
`style`, `iframe`, `a`, обработчик события или `id` выбрасываются вместе с
содержимым. Встроенный `style` может загружать только `data:`-картинки.

## Сообщения

Макет сообщения может расставить такие части:

| Часть | Что это |
|-------|---------|
| `header` | Вся шапка: аватар, имя и время. |
| `avatar` | Только аватар. |
| `name` | Имя с номером сообщения и значком памяти. |
| `time` | Время и глаз скрытого сообщения. |
| `guidance` | Блок указания, если он есть. |
| `content` | Рассуждения, тело сообщения, картинки и подвал. |
| `footer` | Стрелки свайпов, перегенерация и меню. |

В шаблон сообщения приходят такие поля:

| Поле | Значение |
|------|----------|
| `id`, `role`, `isUser`, `isChar`, `isSystem` | Кто и какое это сообщение. |
| `name`, `initial`, `avatarUrl`, `avatarColor`, `persona` | Отправитель. |
| `text`, `reasoning` | Текст в том виде, в каком его отформатировало приложение. |
| `timestamp`, `time`, `date` | Метка времени и готовые подписи. |
| `index` | Номер сообщения с единицы или пусто, если он неизвестен. |
| `swipe.index`, `swipe.total` | Текущая вариация и сколько их всего. |
| `tokens`, `genTime`, `model` | Статистика генерации; пусто, если её нет. |
| `isLast`, `isError`, `isHidden`, `isTyping` | Флаги состояния. |

`g-action` на элементе сообщения вызывает действие приложения, уже привязанное
к этому сообщению:

```
open-actions, regenerate, translate, swipe-left, swipe-right,
greeting-prev, greeting-next, agent-swipe-left, agent-swipe-right,
memory-click, inject-click, toggle-hidden, output-limit-click,
rerun-cleaner, toggle-guided, edit-save, edit-cancel, stop
```

## Шапка, поле ввода и ящик

Части шапки: `back`, `title` (весь блок заголовка), `character` (только блок
персонажа), `avatar`, `name`, `session` и `search`. Поле поиска на телефоне
живёт внутри `title`, поэтому макет с рабочим поиском ставит `title`.
Действия: `back`, `character`, `avatar`, `search` и `closeSearch`.

Части поля ввода: `attachments`, `pill` (поверхность ввода), `guidance`,
`input`, `row`, `pins` и `send`. Текст остаётся в том поле, которое поставил
шаблон, поэтому клавиатура, черновик и отправка работают как раньше.
Действия: `send` и `focus`.

У ящика для карточки есть поля `label`, `status`, `icon`, `statusIcon`,
`kind`, `add`, `editing` и `tab`; для вкладки — `label`, `icon`, `active` и
`index`. Сами карточка и вкладка остаются ящика, поэтому нажатия,
перетаскивание долгим нажатием и значки редактирования работают как прежде.

## Стили

У трёх файлов стилей разная область действия:

- `css` добавляется на страницу чата. Он видит секции сообщений, область
  прокрутки и фон, но не может залезть в хром: тот живёт в закрытом shadow
  root.
- `contentCss` добавляется внутрь shadow root каждого сообщения. Только так
  можно стилизовать то, что пишет Markdown: абзацы, цитаты, списки, код,
  таблицы и ссылки.
- `chromeCss` добавляется внутрь хрома. Им стилизуют то, что нарисовали
  шаблоны шапки, поля ввода и ящика.

Все три проходят через санитайзер. `url()` может загружать только
`data:`-картинки; `@import`, `@font-face`, `expression()` и экранирование,
которое может спрятать `url()`, выбрасываются вместе с правилом. Файл темы
передают другим, поэтому он не должен уметь отправить куда-то то, что ему
показали.

Страница и хром также отдают активную тему переменными CSS. На странице
полезны `--user-bubble-bg`, `--char-bubble-bg`, `--user-text-color`,
`--char-text-color`, `--user-quote-color`, `--char-quote-color`,
`--user-italic-color`, `--char-italic-color`, `--user-bubble-radius`,
`--char-bubble-radius`, `--element-opacity`, `--element-blur`,
`--avatar-radius`, `--font-size`, `--font-family`, `--text-bg-opacity` и
`--bg-dim`.

У хрома свои: `--gc-accent`, `--gc-text`, `--gc-text2`, `--gc-corner`,
`--gc-fill`, `--gc-fill-header`, `--gc-fill-surface`, `--gc-outline`,
`--gc-outline-var`, `--gc-font`, `--gc-bw`, `--gc-bc`, `--gc-safe-top` и
`--gc-safe-bottom`.

## Настройки темы

`layout.settings` — это объявление или путь к JSON-файлу, который заменяет
встроенный экран «Чат» в редакторе. Оно описывает вкладки, группы в каждой
вкладке и строки в каждой группе:

```json
{
  "tabs": [
    {
      "id": "theme",
      "label": { "en": "Theme", "ru": "Тема" },
      "icon": "brush",
      "groups": [
        {
          "header": { "en": "Cards", "ru": "Карточки" },
          "items": [
            {
              "type": "color",
              "key": "card-edge",
              "label": { "en": "Card edge", "ru": "Кромка" },
              "default": "#C42A4A"
            },
            {
              "type": "slider",
              "key": "card-pad",
              "label": { "en": "Padding", "ru": "Отступ" },
              "min": 4,
              "max": 24,
              "step": 1,
              "unit": "px",
              "default": 12
            },
            {
              "type": "switch",
              "key": "compact",
              "label": { "en": "Compact header", "ru": "Компактная шапка" }
            },
            { "field": "userBubbleColor", "when": "chatLayout == 'bubble'" }
          ]
        }
      ]
    }
  ]
}
```

Строка — это одно из:

| Строка | Значение |
|--------|----------|
| `{"field": "..."}` | Поле пресета, нарисованное так же, как на встроенном экране. |
| `{"type": "color", "key": "..."}` | Цвет, принадлежащий теме. |
| `{"type": "slider", "key": "...", "min": 0, "max": 10}` | Число; `unit` — `px`, `%`, `em`, `rem`, `deg`, `s` или `ms`, а `percent` показывает значение умноженным на 100. |
| `{"type": "switch", "key": "..."}` | Переключатель. |
| `{"type": "select", "key": "...", "options": [...]}` | Выбор из `options`; у каждого варианта есть `value` и `label`. |
| `{"type": "subheader"}` или `{"type": "note"}` | Подзаголовок или пояснение, с `label`. |

Тема может привязывать поля `chatLayout`, `chatBgMode`, `chatBgColor`,
`chatBgImage`, `chatFontMode`, `chatFontSize`, `chatLetterSpacing`,
`userMessageFontWeight`, `charMessageFontWeight`, `userBubbleColor`,
`charBubbleColor`, `userBubbleRadius`, `charBubbleRadius`, `showUserAvatar`,
`showCharAvatar`, `showUserName`, `showCharName`, `hideMessageId`,
`hideGenerationTime`, `hideTokenCount`, `userQuoteColor`, `charQuoteColor`,
`userTextColor`, `charTextColor`, `userItalicColor`, `charItalicColor` и
`textBgOpacity`.

Подписи — строка, по строке на язык, или `"@key"` для перевода приложения.
Иконка вкладки — одна из `text_fields`, `palette`, `tune`, `chat`, `image`,
`brush`, `star`, `layers`, `person` или `auto_awesome`.

`when` у группы или строки показывает их, только пока условие истинно. Оно
читает поля пресета выше, собственные значения темы по ключу и `desktop` /
`mobile`; доступны `!`, сравнения, `&&`, `||`, скобки, строки, числа, `true`,
`false` и `null`.

Собственные значения темы попадают в макет тремя способами, одинаково на
странице и в хроме:

| | |
|---|---|
| `--theme-<key>` | Переменная CSS: цвет, число с единицей, `1`/`0` для переключателя или выбранный вариант. |
| `theme-<key>` | Класс, пока переключатель включён. |
| `theme-<key>-<value>` | Класс для выбранного варианта списка. |

На странице переменные лежат на документе, а классы — на `#chat-container`;
в хроме и то и другое на его корне. Шаблон сообщения получает их как
`theme.<key>`, поэтому работает `g-if="theme.compact"`. Проходят только
цвета, числа и простые слова.

## Шаблон и превью

`docs/theme_template` в репозитории — рабочая тема: шаблон сообщения, стили
страницы и хрома, а также `settings.json` со встроенным экраном «Чат» и
одной вкладкой собственных настроек. Заархивируйте содержимое папки, чтобы
`theme.json` был в корне, и импортируйте архив.

Кнопка с глазом в шапке редактора показывает ту же страницу, что и чат, с
несколькими примерными сообщениями. Что показывает превью, то и будет в
чате.
