Glaze — это локальный, удобный ИИ-клиент для ролевых чатов. Работает с любым OpenAI-совместимым (Chat Completion) LLM-провайдером и хранит ваши данные на вашем устройстве.

> [!WARNING]
> Glaze всё ещё находится в стадии активной разработки. Приложение пока нестабильно и может содержать ошибки.
>
> 🧪 **Дисклеймер**: Это приложение было **vibecoded** с помощью плеяды моделей. Умерьте свои ожидания.

## ✨ Основные Особенности

- **Простая Установка и Удобный Интерфейс** — Вам не требуются глубокие познания в ИТ, чтобы пользоваться приложением. Просто установите его и начните общаться.
- **Реально Работающая Статистика Пользователя** — Получайте наглядную информацию о том, сколько сообщений вы отправили, сколько токенов потратили и сколько часов провели в чатах.
- **Нативная Поддержка Моделей с Рассуждениями (Reasoning)** — Больше никаких регулярных выражений. Встроенные рассуждения корректно распознаются и помещаются в отдельный блок, который не отправляется обратно модели. Если в вашем пресете используются собственные теги для рассуждений, Glaze может обрабатывать и их.
- **Гибкая Темизация** — Изменяйте цвета, шрифты и фоновые изображения, а затем экспортируйте свою тему в виде JSON-файла, чтобы поделиться ею с другими. Material 3 на всех платформах, с раздельными макетами для десктопа и мобильных устройств.
- **Фоновая Генерация** — Glaze может генерировать ответы в фоновом режиме и уведомит вас, когда всё будет готово.
- **Лорбуки и Память** — Подключайте лорбуки, книги памяти, заметки автора и персоны для связности длительных ролевых игр.
- **Генерация Изображений** — Создавайте изображения прямо в приложении и встраивайте их в сценарии ролевых игр и блоки расширений.
- **Облачная Синхронизация** — Опциональная синхронизация через Dropbox и Google Drive для переноса данных между устройствами.
- **Локальное Хранилище** — Персонажи, сессии, пресеты, конфигурация API, персоны, лорбуки и данные расширений хранятся в локальной базе SQLite.
- **Расширения (ExtBlocks)** — Автоматические действия после генерации: информационные блоки, создание изображений, JS-скрипты и интерактивные HTML-панели. *(на стадии доработки)*
- **Glaze Studio** — Многоагентная обработка для улучшения качества ответов: очистка, проверка фактов, система сущностей и ограничений. *(на стадии доработки)*

## 🤝 Базовая Совместимость с SillyTavern

- **Пресеты** — Все JSON-пресеты SillyTavern совместимы с Glaze. Несколько популярных пресетов предустановлены.
- **Продвинутая Система Макросов** — Базовая поддержка макросов (полная совместимость с SillyTavern в процессе). Переменные (setvars/getvars), случайный выбор, броски кубиков и подстановка данных персонажа/пользователя полностью поддерживаются.
- **Совместимость с Карточками Персонажей** — Импорт и экспорт карточек персонажей в формате SillyTavern V2 (JSON и PNG).
- **Лорбуки (World Info)** — Полная поддержка лорбуков для улучшения ролевого опыта.
- **Поддержка Regex** — Полная поддержка скриптов регулярных выражений, включая те, что встроены в ваши любимые пресеты.

## 🧩 Расширения

Glaze включает изолированную систему расширений для постгенерационной автоматизации и интерактивных UI-блоков.

- **Блоки постгенерации** — Запуск `infoblock`, `imageGen`, `jsRunner` и `interactive` блоков после сообщений ассистента и после сообщений пользователя.
- **Интерактивные панели** — Отображение HTML-панелей расширений под сообщениями ассистента без предоставления скриптам same-origin доступа к приложению.
- **JS Extension SDK** — Изолированные скрипты могут использовать `window.glaze.*` API для переменных, генерации текста, инъекции промптов, аудио, выполнения команд, тостов и многого другого.
- **Права доступа (Capabilities)** — Каждый метод моста защищён явными правами на каждый пресет. По умолчанию — запрет.
- **Области переменных** — Расширения могут использовать области `chat`, `character`, `global` и `message` через специальные API хранилища.

Подробнее об архитектуре моста и инвариантах безопасности см. `docs/ARCHITECTURE.md`, раздел 9, и `docs/INVARIANTS.md`.

## 📥 Установка

Загрузите последний релиз со страницы [Releases](../../releases).

- **Android** — Установите APK-файл напрямую на ваше устройство.
- **iOS** — Установите IPA методом неофициальной загрузки (sideloading) через [AltStore](https://altstore.io/) или аналогичный инструмент. Приложение пока недоступно в App Store.
- **Windows** — Загрузите сборку для Windows и запустите её на своём ПК.
- **macOS / Linux** — Собираются из исходников, но ещё не публикуются как готовые сборки; упаковка и подпись в планах.

Резервные копии из **SillyTavern** (`.zip`) можно импортировать через **Меню → Бекапы**.

## 🛠️ Разработка

Создано на Flutter с локальным SQLite-хранилищем, нативной поддержкой десктопа и изолированным окружением для расширений. Используется Riverpod, Drift/SQLite, Dio, GoRouter и WebView-рендеринг чата.

### 📋 Предварительные Требования

- [Flutter](https://docs.flutter.dev/get-started/install) 3.44+ (или новее, совместимый с Dart 3.12+)
- Инструментарий для целевой платформы — [Android Studio](https://developer.android.com/studio) для Android, Xcode для iOS/macOS, Visual Studio с нагрузкой C++ для десктопа для Windows
- Git

git clone https://github.com/hydall/Glaze.git
cd Glaze
